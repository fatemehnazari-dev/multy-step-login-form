# Multi-Step Login Form

A responsive multi-step registration/login form built with vanilla JavaScript — guides the user through 4 stages (Basic Info → Contact → Birth Info → Login Details) with a visual progress bar, instead of overwhelming them with one long form.

🔗 [Live Demo](https://fatemehnazari-dev.github.io/multy-step-login-form/)

## Features
- 4-step form flow: Name → Contact → Birth Info → Login Details
- Animated progress bar showing current step
- Next / Previous navigation between steps
- Password field with show/hide toggle
- Client-side password validation
- Fully responsive layout

## Built With
- HTML5
- CSS3
- JavaScript (Vanilla, ES6)


## Project Structure
📄 index.html
📄 style.css
📄 script.js

## What I Learned
Working on this project helped me practice DOM manipulation for multi-step navigation, managing form state across steps without a framework, and writing clean, reusable JavaScript for input validation.
